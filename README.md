# wetlipps — staging site

Static, self-contained mockup site for the wetlipps brand (all images embedded as data URIs).

- `index.html` — homepage
- `product.html` — The Gloss Wand product page (template for all SKUs)
- `story.html` — Our Story

Staging/preview only. The production store will be rebuilt as a Shopify (Dawn) theme using
these pages as the design spec — this repo is the reference, not what gets uploaded to Shopify.
